# Deep Learning Portfolio 🧠⚡

A collection of Deep Learning architectures, computer vision pipelines, regularization techniques, and sequence models implemented in Python using Jupyter Notebooks. This repository covers neural network fundamentals up through deep transfer learning and sequential processing.

---

## 📂 Repository Structure & Project Overview

| Notebook | Focus Area | Architecture / Technique | Description |
| :--- | :--- | :--- | :--- |
| **`VGG19.ipynb`** | Computer Vision / Transfer Learning | VGG-19 CNN Architecture | Deep convolutional neural network implementation leveraging 19-layer architecture with pre-trained feature extraction and fine-tuning. |
| **`RNN.ipynb`** | Sequential Modeling / NLP | Recurrent Neural Network | Handling temporal patterns and sequential dependencies using recurrent cells and hidden state transitions. |
| **`Image Enhancement.ipynb`** | Computer Vision & Preprocessing | Filters, Contrast, Restoration | Spatial transformations, noise reduction, and enhancement techniques to optimize image quality before downstream training. |
| **`Dropout Regularization.ipynb`** | Model Optimization & Regularization | Dropout Inverted Scaling | Preventing overfitting in deep networks by randomly deactivating neurons during training phases. |
| **`Linear regression.ipynb`** | Neural Network Fundamentals | Single-Layer Perceptron / Gradient Descent | Implementing linear regression through optimization techniques (cost function minimization and weight updates). |

---

## 🛠️ Tech Stack & Dependencies

- **Language:** Python 3.8+
- **Deep Learning Frameworks:** TensorFlow / Keras or PyTorch
- **Computer Vision & Image Processing:** OpenCV (`cv2`), PIL (Pillow)
- **Scientific Computing & Visualization:** `numpy`, `matplotlib`, `seaborn`
- **Environment:** Jupyter Notebook / Google Colab
